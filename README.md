# Movie-Website-System
【万字文档+源码】基于springboot+vue电影网站系统-可用于毕设-课程设计-练手学习-学习资料分享-基于SpringBoot的电影网站系统开发方案 本项目旨在构建一个轻量级的影视交流平台，采用SpringBoot+Vue前后端分离架构。系统分为前台影迷门户和后台管理系统两大模块： 核心功能： 前台功能：用户注册登录、电影信息浏览、收藏电影、发布影评、阅读资讯和长评 后台管理：电影分类管理、影片信息维护、轮播图设置、资讯发布、用户管理 技术方案： 后端：SpringBoot+MyBatis+MySQL 前端：Vue+Element UI 特色：支持Token鉴权、文件上传、富文本编辑等功能 数据库设计： 包
